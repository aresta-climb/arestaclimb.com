# Política de Privacidade do Editor Aresta Climb

**Última atualização:** Agosto de 2026

O **Editor Aresta Climb** é um aplicativo de código aberto voltado para a criação e gerenciamento de croquis de escalada e dados geográficos. A sua privacidade é importante para nós.

Esta política descreve de forma transparente como os seus dados são tratados durante o uso do Editor.

---

## 1. Coleta e Uso de Dados

O Editor Aresta Climb **não coleta, não armazena em servidores próprios, não rastreia e não vende** nenhuma informação pessoal ou dado de uso. 

O aplicativo opera integralmente na sua máquina local e se comunica apenas com os seguintes serviços estritamente necessários para o seu funcionamento:

### Autenticação e Sincronização (GitHub)
Para permitir que você sincronize os croquis de escalada (operações de *push* e *pull*) diretamente com o banco de dados oficial, o aplicativo solicita autenticação através do **GitHub**.
- O Editor gerencia um token de acesso pessoal gerado localmente.
- O token é utilizado exclusivamente para autenticar o envio e recebimento de arquivos do seu repositório no GitHub.
- Nenhuma credencial ou dado do seu perfil do GitHub é transmitido para os mantenedores do Aresta Climb ou servidores de terceiros. A comunicação ocorre exclusivamente entre o seu computador e os servidores da Microsoft/GitHub.

### Comunicação com Dispositivos Locais
O Editor possui a funcionalidade de iniciar um servidor local na sua máquina para se comunicar com o aplicativo móvel do Aresta Climb no seu próprio celular.
- Esta comunicação acontece **estritamente na sua rede local (Wi-Fi)**.
- Nenhum dado dessa comunicação trafega pela internet ou é enviado para servidores externos.

## 2. Telemetria e Rastreamento

O Editor Aresta Climb **não** possui nenhum tipo de telemetria, cookies embutidos, pixels de rastreamento ou análises de comportamento. Nós não sabemos quando você usa o aplicativo, com que frequência, ou quais montanhas você está editando.

## 3. Código Aberto e Transparência

Por sermos um projeto de código aberto, todo o funcionamento do aplicativo e a forma como a rede é utilizada podem ser auditados publicamente. Se você tiver qualquer dúvida sobre o código-fonte, sinta-se à vontade para inspecioná-lo no nosso repositório oficial.

## 4. Contato

Se você tiver alguma dúvida sobre como seus dados são tratados enquanto você utiliza o Editor Aresta Climb, entre em contato conosco através do repositório no GitHub ou pelo nosso e-mail oficial (disponível na página principal do projeto).

Editor Aresta (Beta)

O canal de testes do Editor Aresta permite experimentar as novidades, melhorias de performance e novas ferramentas de desenho de croquis antes do lançamento geral na Microsoft Store.

Coexistência Garantida: Você pode manter a versão oficial da Microsoft Store e a versão Beta instaladas simultaneamente no mesmo computador. Elas possuem identidades separadas no Windows.
1

Preparar o Windows

O canal Beta é assinado com nosso certificado de testes. Ao abrir o arquivo, confirme as duas etapas normais do Windows: primeiro clique em "Executar" (Aviso de Segurança) e em seguida em "Sim" (permissão de Administrador). O navegador abrirá a confirmação automaticamente.

Baixar Script de Configuração (.bat) Confirme "Executar" e depois "Sim" na janela de Administrador (UAC).
2

Instalar o Editor Beta

Após rodar o script do Passo 1, seu Windows está pronto. Baixe o instalador abaixo e abra o arquivo para iniciar a instalação com atualizações automáticas.

Baixar e Instalar Editor Aresta Beta Ao baixar, abra o arquivo para iniciar o instalador oficial.
Aviso do Windows SmartScreen: Na primeira vez que abrir o instalador, se o Windows exibir uma tela azul avisando que o aplicativo é desconhecido, clique em "Mais informações" e depois em "Instalar assim mesmo". As atualizações subsequentes serão 100% silenciosas e automáticas.
